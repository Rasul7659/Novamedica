# Novamedica: сайт клиники и админка (PHP)

> Ветка **`php`**: серверная часть на PHP 8.2+ для обычного виртуального хостинга (Timeweb и подобные). Так сайт работает в боевом режиме. Версия на Node.js лежит в ветке `node`, полная сборка с обоими вариантами в `main`.

Адаптивный лендинг клиники и админ-панель по адресу **`/admin`**. Правки в админке сначала сохраняются как черновик и попадают на сайт только после кнопки «Опубликовать».

## Требования

PHP 8.2+ с расширениями mbstring, gd, curl (exif желательно), Apache с `mod_rewrite` и поддержкой `.htaccess`. База данных не нужна: данные хранятся в JSON-файлах.

## Структура

```
index.php        точка входа: лендинг, предпросмотр, заявки, оболочка админки, API
php/             логика: вход, API админки, публикация, фото, рендер лендинга
.htaccess        маршрутизация и закрытые пути
public/          CSS, JS и картинки лендинга
admin/           интерфейс админки (vanilla JS, без сборки)
uploads/         загруженные фото (внутри только .htaccess, запрещающий исполнение файлов)
config.example.php   образец настроек
router-dev.php   роутер для локального php -S
deploy/          загрузка на хостинг по FTP
test/           сквозные проверки по HTTP (включая миграцию старых данных)
```

## Что умеет админка

| Раздел | Что делает |
|---|---|
| Главная | новые заявки, число неопубликованных изменений, что осталось заполнить |
| Заявки | статусы (новая → ждём ответа → записан / отказ), заметки, звонок и WhatsApp в один клик, уведомления в Telegram |
| Тексты и контакты | заголовки, телефон, адрес, реквизиты, **номер лицензии**, предпросмотр блока |
| Услуги и цены | добавить, изменить, скрыть (удалять нельзя, только скрывать) |
| Врачи | карточки с фото, стаж, скрытие; **специальности** добавляются, переименовываются и удаляются в админке (по ним работает фильтр на сайте) |
| Фото и видео | загрузка (сжатие, удаление EXIF), выбор мест на сайте, замена, удаление неиспользуемых |
| Публикация и история | список изменений, «Не публиковать», предпросмотр `/preview`, откат к прошлой версии |

Без номера лицензии публиковать нельзя.

## Локальный запуск и проверка

```bash
ADMIN_PASSWORD='пароль' php -S 127.0.0.1:8080 router-dev.php   # http://127.0.0.1:8080/admin
npm install && npm test                                         # нужен Node.js только для тестов
```
Логин по умолчанию `admin@novamedica.ru` (меняется через `ADMIN_EMAIL`).

## Развёртывание на хостинге

1. **Загрузка по FTP:**
   ```bash
   python3 deploy/ftp_upload.py --host ХОСТ --user ЛОГИН --remote /папка/сайта/public_html [--plain]
   ```
   Пароль FTP скрипт спросит сам (ввод скрыт) и нигде не сохраняет. Сначала он пробует защищённое соединение (FTPS); `--plain` включает обычный FTP. Чтобы найти нужную папку, запустите с `--list`. Загружается только PHP-версия; остатки Node-версии на сервере удаляются.
2. **Настройки.** Создайте `config.php` по образцу `config.example.php` (можно загрузить скриптом: `--config файл`). Обязательно: `ADMIN_EMAIL`, `ADMIN_PASSWORD`, `TRUST_PROXY => '1'`, `PUBLIC_URL`. Файл закрыт от браузера. Администратор создаётся при первом обращении к сайту, после этого пароль из `config.php` можно удалить.
3. **Данные** лежат в папке `novamedica-data` рядом с папкой сайта (вне веба; если создать её нельзя, в `data/` внутри сайта, закрытой `.htaccess`). Делайте её резервные копии.
4. **Почта.** Письмо со ссылкой для сброса пароля уходит функцией `mail()` хостинга от имени `MAIL_FROM` (ящик на вашем домене).
5. **HTTPS.** Включите сертификат и перенаправление на HTTPS, затем укажите `https://…` в `PUBLIC_URL`.

## Безопасность

- Пароль хранится в хеше (bcrypt); 5 неверных попыток блокируют вход на 15 минут.
- Сессия — подписанный HttpOnly-cookie (`SameSite=Lax`): 12 часов или 30 дней при «Запомнить меня». Смена пароля завершает все сессии.
- Изменяющие запросы админки требуют заголовок `X-Requested-With` (защита от CSRF).
- Загрузки проверяются по содержимому файла, фото пересжимаются, метаданные (в том числе GPS) удаляются; в `uploads/` запрещено исполнение PHP.
- Весь пользовательский текст экранируется при выводе, действует строгая CSP; служебные папки закрыты в `.htaccess`.
- Форма заявки: ограничение частоты, скрытое поле-ловушка для ботов, обязательное согласие на обработку данных.

## Что осталось на стороне клиники

Номер лицензии, телефон, адрес, реквизиты, цены, фамилии и фото врачей, фото интерьера (сейчас везде визуализация), тексты политики конфиденциальности и согласия на обработку данных (ссылки в подвале пока ведут вниз страницы).
