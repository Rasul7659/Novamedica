# Novamedica: сайт клиники и админка

Адаптивный лендинг клиники и админ-панель по адресу **`/admin`**. Правки в админке сначала сохраняются как черновик и попадают на сайт только после кнопки «Опубликовать».

Серверная часть есть в двух вариантах с одинаковым API и одним и тем же интерфейсом:

| Ветка | Стек | Где запускать |
|---|---|---|
| **`main`** | всё вместе: общий фронтенд, PHP и Node.js | основная, актуальная версия |
| **`php`** | PHP 8.2+, Apache (`.htaccess`) | обычный виртуальный хостинг (Timeweb и подобные), **так сайт работает сейчас** |
| **`node`** | Node.js ≥ 18, Express | VPS, Render, Railway, Docker |

Нужна только одна серверная часть: берите ветку под свой хостинг. В `main` лежит всё сразу.

## Структура

```
public/      CSS, JS и картинки лендинга (общие)
admin/       интерфейс админки, vanilla JS без сборки (общий)
index.php    PHP: точка входа          php/   PHP: логика      .htaccess, router-dev.php, config.example.php
server/      Node.js: логика           app.js Node: запуск на Passenger      Dockerfile, .env.example
deploy/      скрипт загрузки на хостинг по FTP
test/        сквозные тесты API: api.test.js (Node), php.test.js (PHP)
```

## Что умеет админка

| Раздел | Что делает |
|---|---|
| Главная | новые заявки, число неопубликованных изменений, что осталось заполнить |
| Заявки | статусы (новая → ждём ответа → записан / отказ), заметки, звонок и WhatsApp в один клик, уведомления в Telegram |
| Тексты и контакты | заголовки, телефон, адрес, реквизиты, **номер лицензии**, предпросмотр блока |
| Услуги и цены | добавить, изменить, скрыть (удалять нельзя, только скрывать) |
| Врачи | карточки с фото, специальность (работает фильтр на сайте), стаж, скрытие |
| Фото и видео | загрузка (сжатие, удаление EXIF), выбор мест на сайте, замена, удаление неиспользуемых |
| Публикация и история | список изменений, «Не публиковать», предпросмотр `/preview`, откат к прошлой версии |

Без номера лицензии публиковать нельзя.

## Запуск

**PHP-версия** (нужен PHP 8.2+ с mbstring, gd, curl):
```bash
ADMIN_PASSWORD='пароль' php -S 127.0.0.1:8080 router-dev.php   # http://127.0.0.1:8080/admin
npm install && npm run test:php                                 # 22 сквозные проверки
```

**Node.js-версия:**
```bash
npm install
ADMIN_PASSWORD='пароль' npm start                               # http://localhost:3000/admin
npm test                                                        # 23 сквозные проверки
```
Логин по умолчанию `admin@novamedica.ru` (меняется через `ADMIN_EMAIL`). Если в Node-версии не задать `ADMIN_PASSWORD`, пароль сгенерируется и один раз покажется в консоли. В PHP-версии пароль обязательно задаётся в `config.php`.

## Развёртывание

**PHP на виртуальном хостинге.**
1. Загрузка: `python3 deploy/ftp_upload.py --host ХОСТ --user ЛОГИН --remote /папка/сайта/public_html`. Пароль FTP скрипт спросит сам (ввод скрыт) и нигде не сохраняет. `--plain` нужен, если хостинг не поддерживает FTPS.
2. Создайте `config.php` по образцу `config.example.php` (`ADMIN_EMAIL`, `ADMIN_PASSWORD`, `TRUST_PROXY => '1'`, `PUBLIC_URL`). Из браузера файл недоступен. Администратор создаётся при первом обращении.
3. Данные лежат в `novamedica-data` рядом с папкой сайта (вне веба). Делайте их резервные копии.

**Node.js.** Нужен сервер с постоянным диском под `DATA_DIR`. Есть `Dockerfile` (данные в `/data`), переменные окружения описаны в `.env.example`. За прокси включите `TRUST_PROXY=true`.

Для боевого запуска в обоих вариантах: включите HTTPS, задайте надёжный пароль и `PUBLIC_URL`.

## Безопасность

- Пароль хранится в хеше (bcrypt в PHP, scrypt в Node); 5 неверных попыток блокируют вход на 15 минут.
- Сессия — подписанный HttpOnly-cookie (`SameSite=Lax`): 12 часов или 30 дней при «Запомнить меня». Смена пароля завершает все сессии.
- Изменяющие запросы админки требуют заголовок `X-Requested-With` (защита от CSRF).
- Загрузки проверяются по содержимому файла, фото пересжимаются, метаданные (в том числе GPS) удаляются.
- Весь пользовательский текст экранируется при выводе, действует строгая CSP.
- Форма заявки: ограничение частоты, скрытое поле-ловушка для ботов, обязательное согласие на обработку данных.

## Что осталось на стороне клиники

Номер лицензии, телефон, адрес, реквизиты, цены, фамилии и фото врачей, фото интерьера (сейчас везде визуализация), тексты политики конфиденциальности и согласия на обработку данных (ссылки в подвале пока ведут вниз страницы).
